# CHIL Documentation
This repository hosts the source files for documentation regarding CHIL instruments (Cryoegg, Cryowurst) and the datalogger. The documentation can be accessed at the URL below:

https://chilcardiff.github.io/docs/

## Initialising project structure
Following instructions at from the [Sphinx documentation](https://www.sphinx-doc.org/en/master/tutorial/getting-started.html). 

## Building project
On a Windows PC, run `./make.bat html` in the directory root. On a Unix system, call `make html`.
