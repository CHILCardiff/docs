Cryoegg
=======

The Cryoegg wireless instrument is a 120mm sphere with temperature, conductivity, pressure and orientation sensing capabilities. The internal electronics are composed of an upper and lower board which implement the logic and power management, respectively.

This section of the documentation describes the steps required to assembly and program a Cryoegg instrument so it is ready for use, followed by recommendations for deployment in the field.

.. note:: 
   
   Design files and firmware for the Cryoegg sensor are located in the `cryoegg-2025`_ GitHub repository.


.. _cryoegg-2025: https://github.com/chilcardiff/cryoegg-2025
