Cryowurst
---------

The Cryowurst wireless instrument is an 85mm diameter and 270mm long cylinder tapered ends possessing temperature, conductivity, pressure and orientation sensing capabilities. The internal electronics are composed of a motherboard which hosts the logic, power management and radio circuitry; and a lower board which interfaces to the sensors.

This section of the documentation describes the steps required to assemble and program a Cryowurst instrument so it is ready for use, followed by recommendations for deployment in the field.

.. note:: 
   
   Design files and firmware for the Cryowurst sensor are located in the `cryowurst-2026`_ GitHub repository.
