Firmware and programming#

Firmware#

The latest source code for the Cryowurst firmware is stored on GitHub here: CHILCardiff/cryowurst-2026. At present, we do not provide pre-compiled .elf files to program the instrument using STM32CubeProgrammer or similar binary flashing tools.

You should already have downloaded the latest version of the firmware for Cryowurst when setting up your CHIL development environment.

Programming using STM32CubeIDE#

The following section describes the equipment required and necessary steps to program the Cryowurst sensor. Programming the sensor allows the user to change the measurement interval, number of deployment packets and radio packet version used.

Equipment#

To program the Cryowurst, you will need the items shown below in addition to an assembled Cryowurst motherboard, power switch and batteries.

  1. STMicroelectronics STLINK-V3 Programmer for STM32 microcontrollers.

  2. USB-A to Micro-USB cable.

  3. Tag-Connect TC2030-IDC-NL programming cable.

  4. (Optional) Tag-Connect TC2030-CLIP retaining board.

Steps#

  1. Connect the Tag-Connect cable to the STLINK-V3 programmer using the exposed connector underneath and connect the STLINK-V3 to your PC.

  2. Insert the Tag-Connect cable to connector J2 on the Cryowurst motherboard on the same side as the radio module and microcontroller.

  3. If using the retaining clip, press this onto the Tag-Connect pins on the other side of the board.

  4. Connect a battery and power switch (POWER_EN). You are now ready to program the Cryowurst.

Note

It can be easier to disconnect the motherboard from the sensorboard while programming the Cryowurst to avoid damaging the header. If you are diagnosing problems with the EC, temperature or pressure sensors, then ensure that the sensorboard is connected.

The following steps assume you have set up your the CHIL development environment. If not, follow the setup instructions and then return to this step when completed.

  1. Open STM32CubeIDE and ensure that the cryowurst-2026 and chillib projects are open (check by right-clicking in the Project Explorer window).

  1. Find Core/Src/main.c in the Project Explorer and open the file. Scroll down to the int main(void) function (Line 118 at time of writing). This section defines the deployment behaviour of the instrument. If you wish to modify the behaviour, update these values in main.c. Each value is described below in the table below:

Note

When defining sleep periods, account for the time period the instrument takes to make each measurement by subtracting 3 seconds from the desired value. For example, to have a deployment interval of 30 seconds, set deployment_sleep_period_s = 27.

  1. Open the Debug Configurations dialog box from Run > Debug Configurations in the top menu bar.

  1. If there is no configuration available under STM32 C/C++ Application and ensure that the Debugger settings match those in Figure 40.

  2. When you are ready to program the Cryowurst, press the Debug button in the Debug Configurations dialog box.

  1. If you succesfully program the Cryowurst, you should see output in the Console which matches Figure 41. The programmer has halted execution of the program at the start of the main function. At this point, you can choose to:

    1. Disconnect the programmer and power from the Cryowurst and test it at a later date.

    2. Continue to run the program and check sensor outputs (see Step 11) by pressing the resume icon (pink arrow in Figure 41).

  2. Open the Serial Wire Viewer Output window to check the instrument is working. If you have not previously configured the Serial Wire Viewer, follow the instructions here.

You have now succesfully programmed the Cryowurst for deployment. We recommend powering off the instrument and restarting it without the programming cable inserted before deployment.

Tip

It is possible to reset the number of deployment packets when programming the Cryowurst by following the steps below.

  1. Insert a breakpoint (right-click line number and select Toggle Breakpoint) below the line in main() where chil_instrument_init(&cyrowurst, &hrtc) is called.

  1. Run the program until this breakpoint is activated.

  2. Hover the mouse cursor over &cryowurst until the variable dialog window is shown. Double click the value of deployment_packets and set it to the new value.

  1. Continue to run the program until the Cryowurst enters sleep mode so that the new deployment_packets value is saved.

Configuring Serial Wire Viewer (SWV)#

To configure the serial wire viewer (SWV) to view debugging data from CHIL instruments, follow the instructions below:

  1. If not already open, create a new SVW ITM Data Console Window by selecting Window > Show View > SWV > SWV ITM Data Console from the top menu bar.

  1. Open the settings by selecting the “tools” (spanner and screwdriver) menu in the top right of the SWV ITM Data Console Window. Copy the settings below from Figure 44.

  1. Press the Start Trace button (red circle) to enable logging. When logging is enabled, the button will have a blue highlight around it. Viewing the ITM Data Console window during debugging will show any SWV output from the instrument.
